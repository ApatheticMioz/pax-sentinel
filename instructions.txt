## 2. Game Mechanics & Dynamics
- **Game Type**: Three-Way Repeated Peace-War (a 3-player variant of the Continuous/Repeated Prisoner's Dilemma).
- **Actions**:
  - `0`: Peace
  - `1`: War
- **Match Structure**:
  - Triples of agents are matched against each other and play repeatedly.
  - Each match consists of approximately 100 rounds.
  - A player's match score is the average of the payoffs earned in each round:
    $$\text{Score} = \lim_{k \to \infty} \frac{1}{k} \sum_{j=1}^{k} r_j \quad (\approx \text{average payoff over ~100 rounds})$$
- **Game Theoretic Context**:
  - In a single-stage Peace-War game, the dominant strategy equilibrium is for all agents to choose War (1), even though all players achieve mutual benefit by choosing Peace (0).
  - In repeated play, cooperative equilibria can emerge. Strategies can track historical interactions to reward cooperation or punish defection (e.g., Tit-for-Tat, Grim Trigger).

## 3. Agent Interface & Technical Specification
- **Language**: C++ (compiled via `g++ ThreeWayPeaceWar.cpp`).
- **Base Class**: Inherits from `Agent`.
- **Method Signature**:
```cpp
class <YourAgentName> : public Agent {
public:
    int selectAction(int n,
                     const std::vector<int>& myHistory,
                     const std::vector<int>& oppHistory1,
                     const std::vector<int>& oppHistory2);
};
```
- **Parameters**:
  - `n`: Total number of rounds elapsed so far in the current match.
  - `myHistory`: `std::vector<int>` containing your agent's past actions in the match.
  - `oppHistory1`: `std::vector<int>` containing Opponent 1's past actions in the match.
  - `oppHistory2`: `std::vector<int>` containing Opponent 2's past actions in the match.
- **Return Value**: Integer action for the current round (`0` for Peace, `1` for War).
